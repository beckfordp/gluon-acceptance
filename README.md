# gluon-acceptance

BDD acceptance suite for the [Gluon](https://github.com/beckfordp/gluon) platform.
Acceptance criteria are Gherkin `.feature` files, compiled by
[playwright-bdd](https://github.com/vitalets/playwright-bdd) and run by Playwright,
driving gshop against the real local cluster. Each scenario is tagged with the
`@US-N.M` it accepts in Gluon's
[`docs/user-stories.md`](https://github.com/beckfordp/gluon/blob/main/docs/user-stories.md).

See [ADR 0020](https://github.com/beckfordp/gluon/blob/main/docs/adr/0020-playwright-acceptance-tests.md)
(Playwright through gshop), [ADR 0023](https://github.com/beckfordp/gluon/blob/main/docs/adr/0023-bdd-acceptance-tests-playwright-bdd.md)
(Gherkin via playwright-bdd) and Gluon's `PLAN.md` "Acceptance Testing".

## Prerequisites

- Node 24 (`.nvmrc`: `nvm use`, or Homebrew's `node`). Playwright 1.64 needs Node ≥ 20.
- npm 11 (ships with Node 24)
- The Gluon platform deployed to the local OrbStack cluster (namespace `gluon-local`)
- gshop at `../../frontends/gshop`, i.e. this repo cloned at `gluon/tests/acceptance`,
  with its npm deps installed (`npm ci` there)

No GitHub Packages token is needed.

## Setup

```
npm ci
npx playwright install chromium
```

## Layout

- `features/`: Gherkin feature files, tagged `@US-N.M`
- `steps/`: step definitions (`createBdd(test)`), thin, delegating to `src/`
- `src/`: fixtures, page objects, config; pure parts unit-tested
- `tests/unit/`: vitest unit tests
- `.features-gen/`: specs generated by `bddgen` (gitignored)
- `conductor/`: product, tech stack, workflow and tracks

## Checks

```
npx bddgen && npm run lint && npm run typecheck && npm test
```

This is what CI runs (no cluster, no browsers). `npm run test:coverage` enforces
>80% coverage on `src/`.

## Running the suite

```
npm run test:acceptance
```

This runs `bddgen`, then Playwright. Playwright starts gshop's Vite dev server (or reuses
one already on :5173), wired to the services' in-cluster DNS names, which OrbStack resolves
on the Mac. No port-forwards are needed. Features run in Chromium.

- Report: `npx playwright show-report` (each Gherkin step shown); traces kept on failure

### Watching a run

| Command | What you see |
|---|---|
| `npm run test:acceptance:ui` | Playwright UI mode: each scenario's Given/When/Then steps beside gshop live in the browser, with a page snapshot per step. Run, re-run and watch features from there |
| `npm run test:acceptance:headed` | A visible Chromium window, slowed to 500 ms per action (`SLOW_MO=1000 npm run test:acceptance:headed` for slower) |

### Configuration (env vars)

| Variable | Default | Meaning |
|---|---|---|
| `GSHOP_URL` | `http://localhost:5173` | Where gshop is served; its port is passed to Vite |
| `GSHOP_DIR` | `../../frontends/gshop` | gshop checkout the dev server runs from |
| `<SERVICE>_URL` (`ORDER_URL`, `PAYMENT_URL`, `INVENTORY_URL`, `USER_URL`, `CATALOG_URL`, `FULFILMENT_URL`, `CART_URL`, `NOTIFICATION_URL`) | `http://<name>-service.gluon-local.svc.cluster.local:8080` | Service base URL, passed to gshop as `VITE_<NAME>_SERVICE_URL` |

Invalid values fail the run at startup, listing every error.
